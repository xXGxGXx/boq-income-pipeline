# Research Findings

## Purpose

This folder captures research conducted before making decisions in this repository. It is for verified findings, not guesses.

## Rule

Any AI platform working here that lacks knowledge in an area must research before acting. If something cannot be verified, record it as unverified and say what would verify it.

## Format

Add dated markdown files named `research-YYYY-MM-DD.md` (date in Australia/Brisbane). Each entry must include:

- **Source** (link or exact reference)
- **Finding**
- **How it changed a decision**

The starter file `research-2026-11-25.md` mirrors the Handover Protocol Research Findings notes for this date.
