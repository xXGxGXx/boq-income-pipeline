ANDROID DEVICE EDGE

Termux:API bridge

OPTIONAL

Connect the PWA to a loopback-only Termux helper for Android toast, notification, speech, vibration and battery actions. No shell commands are accepted.

Bridge not connected. Start `start_android_bridge.sh` in Termux, then paste its fresh token here.
Setup requires the Termux Android app, the Termux:API companion app from the same trusted distribution source, and `pkg install termux-api`. The bridge binds to 127.0.0.1 only and the token expires when the bridge stops.
