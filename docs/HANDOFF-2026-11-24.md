## 4. Architecture
- **Media Hub:** `tools/build.py` concatenates `src/*.js` in a fixed order and inlines the CSS and the catalog JSON into one page. It builds two outputs: a folder (`media/` + `sw.js`) and a single HTML with media embedded as base64.
  - **Data:** a read-only catalog, a user layer (IndexedDB, backup/restore, restore points, encrypted notes AES-GCM/PBKDF2), and device imports (stored byte-for-byte with SHA-256).
  - **Server:** `media_serve.py` is a stdlib server, loopback-only, with Host/Origin/Sec-Fetch-Site checks, Range 206/416, an allow-list and phone folders at `/library/<name>/`.
  - **Offline:** a service worker (no `clients.claim()`); Termux start script; Tasker WebView player.
- **`orchestrator/orchestrator.py`:** an asyncio router. Each task goes to the Claude Code CLI (`--allowedTools Read,Grep,Glob` by default), the xAI chat API (httpx) or Muse (placeholder API). Token buckets and semaphores limit rate; it retries 429/502–504/network errors and writes JSON + Markdown reports. `artifacts/orchestrator.py` is a second, threaded variant from another assistant.
- **Master skill:** `SKILL.md` routes each request type to a reference file or script; scripts are stdlib-only.
- **Automation Forge 4.2.1 (Android):** a WebView page (`assets/`) calls the `ForgeNative` JS bridge (`MainActivity.kt`). That validates workflows (`ForgePolicy`) and queues WorkManager jobs; `ForgeWorker` runs note/delay/notify/webhook steps and logs to SQLite (`ForgeHistory`).
- **Master Orchestrator:** design only (Termux/proot, termux-mcp, Desktop Commander Remote, Shizuku/ADB single grant, voice routing, Modules A–I). Nothing runs yet except some `skills/` scripts from other assistants.

## 9. Decisions made (and alternatives rejected)

- **Box suite keeps approval "always" and adds the approval round-trip.** Rejected: switching approval off.

- **Forge fixes went into a plain-Kotlin `ForgePolicy`** so they're unit-testable. Webhook delays are capped at 8 minutes per run rather than moving to a foreground service.
- **Took `main`'s copy of the orchestrator fix** when it collided with mine (equivalent code).
