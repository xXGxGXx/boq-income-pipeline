# AI Handover Kit (source)

The kit that hands the AI User Extension project to Grok, ChatGPT, Perplexity, Gemini and Muse (muse.ai), and back to Claude. Start with [`kit/00-START-HERE/README-FIRST.md`](kit/00-START-HERE/README-FIRST.md).

- **Hand-written parts:** `kit/00-START-HERE/README-FIRST.md`, `HANDOVER-PROTOCOL-v4.md`, and everything in `kit/01-*`, `02-*`, `03-*`, `05-*`, `06-*`.
- **Generated by `build_kit.py`:** each platform's self-contained `04-PLATFORMS/<P>/<P>-HANDOVER.md`, the THOUGHTS readmes, `AUTO-START-PROMPTS.md`, `KIT-INDEX.md`, the copies in `07-REFERENCE/`, and `08-TOOLS/`. To change a platform's role, tasks or prompt, edit `PLATFORMS` in `build_kit.py`, not the generated file.

```bash
python3 docs/ai-handover-kit/build_kit.py                         # regenerate after editing anything
python3 docs/ai-handover-kit/build_kit.py --zip AI-HANDOVER-KIT-v4.zip   # plus a zip to hand out (don't commit the zip)
python3 docs/ai-handover-kit/build_kit.py --check                 # exit 1 if kit/ is out of date
cd docs/ai-handover-kit/kit && python3 08-TOOLS/verify_kit.py     # check a received kit is complete and unchanged
```

Nothing private belongs here: this repository is public. Platform finds that are private stay in the owner's Drive copy of the kit, never in this folder.
