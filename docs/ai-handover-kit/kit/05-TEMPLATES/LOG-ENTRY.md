# Log entry formats

MERGE-LOG.md:       `<YYYY-MM-DD HH:MM> · <PLATFORM> · <file or folder> · <one-sentence summary>`
ERROR-AGGREGATOR:   `<ERR-ID> · <severity> · <one line> · same as: <IDs> · status: open / fixed / rejected`
REQUEST-BOARD:      `<REQ-ID> · <FROM> → <TO> · <ask> · status`
IDEAS-BACKLOG:      `<IDEA-ID> · <total score> · <one line> · status: proposed / approved / built / rejected`
TASK-BOARD:         `<TASK-ID> · <PLATFORM> · <task> · status: todo / doing / done / blocked`
RETRIEVAL-INDEX:    `<RET-ID> · <PLATFORM> · <public-safe summary> · <supports / contradicts / adds>`
