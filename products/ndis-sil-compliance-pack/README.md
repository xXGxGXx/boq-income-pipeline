# NDIS SIL Compliance Starter Pack (source)

Source for the buyer pack. Build the buyer zip (Word files and the evidence tracker are generated from these Markdown
files) with:

```bash
pip install python-docx openpyxl
python3 products/build_releases.py --out release-out ndis-sil-compliance-pack
```

| Path | Contents |
|---|---|
| `START-HERE.md` | Buyer introduction, how to use the pack, and safe use of the prompts |
| `workflow.md` | Registration and audit-readiness workflow: pathways, what's assessed, 90-day plan, audit day, ongoing calendar |
| `prompts/` | 11 AI prompts with accuracy guardrails (they mark anything to check as **[VERIFY]**) |
| `templates/` | 11 templates: Module 5A self-assessment workbook, induction and competency record, service agreement outline, supported decision-making record, safeguarding risk register, incident register, complaints and feedback register, continuous improvement register, tenancy and support separation checklist, audit-day checklist, document register |
| `LICENCE.txt` | Buyer licence |

The evidence tracker workbook is generated by `products/office_docs.py`.

## Facts the pack relies on (checked 24 November 2026)
- SIL has needed registration (group 0138) since 1 July 2026. Unregistered providers had until 1 October 2026 to apply: those who applied may continue while they are assessed; those who didn't must stop. Group 0115 registrants have 0138 added to their certificate.
- Module 5A (Schedule 7A of the NDIS (Provider Registration and Practice Standards) Rules 2018) has four standards: supported decision-making; safeguarding; practice governance; and agreements about tenancy, housing and support arrangements. The audit is a certification audit against the Core Module and Module 5A.
- These were confirmed in several secondary sources, consistent with the Commission's mandatory registration page. The Commission's site couldn't be read from the build environment, so the official Module 5A indicators are not quoted. The templates ask buyers to paste them in.
- Reportable incident timeframes in the incident register are flagged for buyers to check.

Not legal advice. Re-check these facts whenever the pack is updated.
