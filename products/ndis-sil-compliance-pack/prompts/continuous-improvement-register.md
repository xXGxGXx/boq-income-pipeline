# Prompt: Continuous Improvement Register

Build a continuous improvement register template for a SIL provider that turns audit findings, incidents, and feedback into tracked actions.

Columns:
- Date raised
- Source (incident, audit, feedback, staff suggestion)
- Issue description
- Action required
- Owner
- Due date
- Status (open / in progress / closed)
- Evidence of completion
- Date closed and reviewed by

Include a short prompt that reviews a quarter of entries and drafts a summary for governance meetings.

Organisation: [insert name]

Output the register as a table plus the quarterly-review prompt.
