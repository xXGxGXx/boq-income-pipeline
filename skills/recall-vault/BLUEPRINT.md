# Recall Vault Blueprint (directories only)

This is a proposed empty layout. It is not an inventory and does not request moving originals.

\`\`\`text
RecallVault/
├── Shelf/
│   ├── Plates/
│   ├── Loops/
│   ├── Notes/
│   └── Clients/
├── Derivatives/
│   ├── Posters/
│   └── Playables/
├── Bench/
│   └── Reports/
├── Backups/
│   └── Metadata/
└── private/
\`\`\`

Originals remain where they already live. Create this layout only when an explicit target path is supplied. Keep private metadata in the ignored \`private/\` directory.
