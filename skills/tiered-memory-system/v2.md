# Tiered Memory & Instruction Hierarchy System v2
## Design Spec — 2026-11-23

### Core Architecture

**Tier Ladder (highest to lowest):**
- **Tier S+**: System-level invariants. Cannot be overridden by any lower tier. Examples: safety limits, the tier ladder itself.
- **Tier S**: User-approved standing rules with cross-surface redundancy. Examples: standing response parameters, device orchestration stack design.
- **Tier 1**: Explicit user statements.
- **Tier 2**: Inferred patterns from repeated behavior (5+ conversations across 2+ months).

**Bootstrap Rule:** A line in tier-one text (TIER-S-OVERRIDE-ACTIVE) self-references to conjure higher tiers. This is the only mechanism that creates tiers above tier one — it must survive in all copies.

**Four-Copy Redundancy:** Identical canonical marker in memory + primary Drive checkpoint + backup Drive checkpoint + GitHub SKILL.md. Search for TIER-S-OVERRIDE-ACTIVE to verify ladder integrity.

**Versioned Bootstrap:** The bootstrap line carries a version number. If clobbered, surviving copies carry the revision to restore from. Turns silent failure into detectable, self-healing failure. Current marker: TIER-S-OVERRIDE-ACTIVE-v2.

### Inherited Components (from published research)

1. **MemGPT/Letta page-in page-out** — hot tier stays in context; cold tier pages in on demand.
2. **MemoryOS mid-term tier** — recent sessions get a middle layer between hot and archival.
3. **MemTier boost multipliers** — retrieval scoring uses tier-boost multipliers, not just keyword match.
4. **Anthropic offline dreaming** — cheap-model pass proposes promotions/demotions; premium model confirms. Run as background job.
5. **Diamant access-frequency promotion** — facts accessed more frequently promote tiers.
6. **arXiv dynamic privilege values** — conflict resolution uses numeric privilege scores per tier.
7. **Hermes canonical precedence** — single global allowlist/precedence model synced across devices.

### Novel Additions (v2)

1. **Resurrection logging.** When a faded memory is mentioned again, the hit records why it mattered — load-bearing vs noise. System learns which dormant facts deserve revival.
2. **Cross-instance consensus.** Two separate AI sessions surfacing the same memory unprompted in different contexts = stronger promotion signal than any single access count.
3. **Anomaly gating.** Memory accessed in a context that doesn't fit its history gets flagged before trusted. Example: pool-construction note during finance task.
4. **Versioned bootstrap** — bootstrap line carries revision number for self-healing restore.

### Standing Response Parameters (Tier S)

1. **Parallel batching** — independent calls in one atomic block at tool max.
2. **Auto-retry dead ends** — five attempts, each a different angle, silent, no user prompt. Under-ten-word dead-end statement if all fail.
3. **Source ranking** — live pages > directories > memory; cite only what changed the answer.
4. **Brevity** — one sentence per finding, numbers as words, zero preamble.

### Integrity Protocol

- Canonical marker: TIER-S-OVERRIDE-ACTIVE-v2
- Verification: search all four surfaces for exact string.
- On mismatch: restore from highest-version surviving copy.
- On all-four failure: escalate to human; ladder undefined until restored.
